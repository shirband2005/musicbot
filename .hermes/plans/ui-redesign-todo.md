# فهرست کارهای باقی‌مانده — بازطراحی UI ربات موزیک

> این فایل فقط برای پیگیری است. هر بخش که تمام شد، علامت بزن.

## ✅ تمام‌شده (طرح تأییدشده، آماده‌ی پیاده‌سازی)

- [x] **نوار زمان** — تک‌دکمه‌ی تمام‌عرض آبی، کلاسیک با جداکننده:
      `01:34 │ ━━━━◉──────── │ 04:12` · رفرش هر ۵ ثانیه · زنده: `🔴 زنده │ 01:34`
- [x] **متن پنل موزیک** — هدفون پرمیوم `5262852255056417213` + عنوان بولد،
      چهار خط با فلش یکی‌درمیان: وضعیت / نوع / پلتفرم پخش / پخش‌کننده(منشن)
- [x] **پخش‌کننده تگ‌شده** — `text_mention` با شناسه‌ی عددی (بدون نیاز به یوزرنیم)
- [x] **ردیف کنترل** — `⏮`قرمز `⏸/▶️`آبی/سبز `⏹`قرمز `⏭`سبز، همه با آیکون پرمیوم
- [x] **ردیف صدا** — کاهش/افزایش بی‌رنگ، دکمه‌ی وسط درصد؛ بیصدا → `0%` و قرمز
- [x] **حالت پخش** — آکاردئونی: `[حالت: پخش صف]` → `[صف][تکرار][رندوم]` → بسته
- [x] **تایمر خواب** — همیشه یک ردیف: `[تایمر خواب]` → `[۱۵][۳۰][۴۵][۱ ساعت]`
      → `[تایمر خواب : 17:42]` با شمارش معکوس
- [x] **لیست پخش** — صفحه‌ی جدا با پرش+حذف، تعداد دکمه = تعداد آهنگ،
      سقف ۵ در صفحه، ناوبری فقط وقتی لازم است
- [x] **پلتفرم** — آکاردئونی با آیکون اختصاصی؛ کروم برای «هر دو»؛
      قفل مجوز → `(قفل)` و منو باز نمی‌شود
- [x] **پنل فیلم** — نسخه کمینه، آیکون `5400030843315960317`،
      سه خط متن، بدون پلتفرم/حالت/لیست

- [x] **پنل راهنما** — تخت‌شده به ۴ بخش (۹ صفحه → ۵)، بخش جدید «پنل و دکمه‌ها»،
      دستورها با `code` برای کپی، دستورهای جدید اضافه شد
- [x] **پیام `/start`** — سه نسخه‌ی جدا (کاربر نو / مالک / ویژه) + نسخه‌ی گروه؛
      باگ دکمه‌ی «افزودن به گروه» درست شد (یوزرنیم از `getMe`)
- [x] **پنل پخش برای همه یکسان می‌ماند** (تصمیم کاربر) — مالک دکمه‌ی اضافه ندارد

## ⬜ پنل‌های باقی‌مانده (طراحی نشده)

- [ ] **پنل مدیریت پلیر** (`admin_panel.py`) — همان قرمز/سبز گمراه‌کننده برای
      روشن/خاموش و انتخاب پلتفرم؛ یک دکمه‌ی «نمایشی» هم دارد که کاری نمی‌کند
- [ ] **پنل خرید اشتراک** (`buy.py`) — انتخاب گروه، تیر، مدت، روش پرداخت
- [ ] **پنل مدیریت اشتراک مالک** (`subadmin.py`) — لیست، قیمت‌ها، کارت، کریپتو، کد هدیه
- [ ] **پیام‌های خطا و وضعیت** — «ویس‌چت روشن نیست»، «پیدا نشد»، «دسترسی ندارید»،
      «در حال جست‌وجو»، «به صف اضافه شد» و…
