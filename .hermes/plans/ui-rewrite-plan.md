## فاز ۰ — پایه‌ها (بدون تغییر رفتار)

**`bot/ui.py`** — تنها منبع حقیقت ظاهر:
- `Builder` (متن + entities با شمارش UTF-16؛ `bold`, `code`, `italic`, `custom_emoji`, `text_mention`)

- `BLUE/RED/GREEN` + `ZW` + `ARROW_BASE`

- `timebar(pos, dur, length=12)` → `01:34 │ ━━━━◉──────── │ 04:12` · بی‌مدت → `🔴 زنده │ mm:ss`
- `fa(n)` ارقام فارسی · `alt_arrow(i)` فلش یکی‌درمیان

- حذف: `gift_codes` (drop نمی‌کنیم، فقط استفاده نمی‌شود)

**`queue.py`**: `Track.uid` (۸ کاراکتر hex) + `Track.requester_id` + سریالایز/دیسریالایز

**تست فاز ۰:** migration روی DB خالی و روی DB موجود · `timebar` در حالت‌های مرزی (۰، انتها، بی‌مدت، >۱ساعت) · یکتایی `uid`

## ریسک‌های شناخته‌شده

- **پنل‌های ماندهٔ در گروه‌ها**: کالبک قدیمی → نگاشت به جدید (فاز ۱)

- **`text_mention` برای کاربر ناشناخته**: اگر ربات کاربر را نشناسد ممکن است رد شود → fallback به متن ساده
