# 🎵 موزیک‌پلیر فارسی تلگرام

رباتی برای پخش **آهنگ و ویدیو** مستقیم داخل ویس‌چت گروه‌های تلگرام، با پنل کنترل کامل فارسی.

## قابلیت‌ها
- 🎵 پخش آهنگ در ویس‌چت (از یوتیوب یا لینک مستقیم)
- 🎬 پخش ویدیو در ویدیوچت
- 📥 جست‌وجو و دانلود از یوتیوب با `yt-dlp`
- 🎛 پنل کنترل فارسی با دکمه‌های اینلاین (مکث، ادامه، رد، صدا، توقف)
- 📊 نوار پیشرفت که هر ۶ ثانیه خودکار بروز می‌شود
- 📜 صف پخش نامحدود (در حافظه)
- 💾 دیتابیس محلی SQLite (بدون نیاز به سرور خارجی)

## معماری
- **کلاینت ربات** (`BOT_TOKEN`): رابط کاربری و دستورات
- **یوزربات کمکی** (`STRING_SESSION`): اکانتی که وارد ویس‌چت می‌شود و پخش می‌کند
- **py-tgcalls**: موتور استریم صدا/ویدیو
- **SQLite**: ذخیره‌ی لیست گروه‌ها و تنظیمات

## متغیرهای محیطی لازم
| متغیر | توضیح |
|---|---|
| `API_ID` | از my.telegram.org |
| `API_HASH` | از my.telegram.org |
| `BOT_TOKEN` | از @BotFather |
| `STRING_SESSION` | رشته نشست یوزربات کمکی (اکانت دوم) |
| `OWNER_ID` | آیدی عددی مالک |
| `LOG_CHANNEL` | (اختیاری) آیدی کانال لاگ رویدادها + بکاپ شبانه |
| `ARCHIVE_CHANNEL` | (اختیاری) آیدی کانال آرشیو آهنگ (ربات باید ادمین باشد) |
| `RESTORE_BLOB` | (اختیاری) رشته‌ی بازیابی خودکفا برای انتقال کامل سرور — پایین را ببین |
| `DB_PATH` | (اختیاری) مسیر فایل دیتابیس — پیش‌فرض `/data/musicbot.db` |
| `COOKIES_FILE` | (اختیاری) مسیر cookies.txt یوتیوب |
| `COVER_PATH` | (اختیاری) مسیر کاور پنل — پیش‌فرض `assets/cover.jpg` |
| `DURATION_LIMIT` | (اختیاری) حداکثر طول محتوا به ثانیه |

## 🚀 دیپلوی سریع روی Railway (یک‌کلیک)

[![Deploy on Railway](https://railway.com/button.svg)](https://railway.com/new/template?template=https://github.com/shirband2005/musicbot)

1. روی دکمه بالا بزن → به Railway می‌روی.
2. یک Volume به مسیر `/data` وصل کن (تا دیتابیس پایدار بماند).
3. متغیرها را پر کن. **دو حالت:**
   - **نصب تازه:** `API_ID`, `API_HASH`, `BOT_TOKEN`, `STRING_SESSION`, `OWNER_ID` و (دلخواه) کانال‌ها را بده.
   - **انتقال از سرور قبلی (تک‌فیلد):** فقط `RESTORE_BLOB` را با رشته‌ی بازیابی
     (فایل `restore_blob.txt` که هر شب در کانال لاگ فرستاده می‌شود) پر کن.
     ربات موقع بوت خودش همه‌ی توکن‌ها و تنظیمات را از آن می‌سازد، سپس اگر
     `LOG_CHANNEL` ست باشد آخرین `musicbot.db` را هم از کانال بازیابی می‌کند.
4. Deploy بزن. تمام. ✅

## 🔄 بکاپ و انتقال سرور
- هر شب ساعت ۰۰:۰۰ به وقت تهران، دو مورد به کانال لاگ فرستاده می‌شود:
  - `musicbot.db` (گروه‌ها، آرشیو، تنظیمات)
  - `restore_blob.txt` (رشته‌ی خودکفای رمزنگاری‌شده‌ی همه‌ی متغیرها؛ کلید رمز داخل خودش است)
- برای انتقال کامل: فقط محتوای `restore_blob.txt` را در فیلد `RESTORE_BLOB` سرور جدید بگذار.
- ⚠️ `restore_blob.txt` را محرمانه نگه دار (شامل همه‌ی توکن‌هاست).

## دستورات
- `پخش اهنگ <نام/لینک>` — پخش آهنگ
- `پخش فیلم <نام/لینک>` — پخش ویدیو
- `مکث` / `ادامه` / `اهنگ بعدی` / `اهنگ قبلی` / `توقف` / `صف`
- `مدیریت پلیر` — پنل مدیریت (فقط مالک)
- `لیست گروه ها` / `لیست ویژه` — فهرست‌ها (فقط مالک)
